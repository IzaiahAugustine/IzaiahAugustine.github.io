# Augustine Arcade

The home page for Izaiah Augustine's games: https://izaiahaugustine.github.io

Each game lives in its own repository and is published with GitHub Pages:

- [Fairway Legends](https://izaiahaugustine.github.io/fairway-ledgends/)
- [Gridlock](https://izaiahaugustine.github.io/gridlock/)
- [Basketball Stat Tracker](https://izaiahaugustine.github.io/basketball-stat-tracker/)

To add a game: publish its repository with GitHub Pages, add a screenshot to `images/` and copy
one of the game cards in `index.html`.
